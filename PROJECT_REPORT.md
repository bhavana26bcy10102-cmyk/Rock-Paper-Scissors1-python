# ROCK-PAPER-SCISSORS GAME
## Python Project Report

### 1. Introduction
Rock-Paper-Scissors is a traditional decision-making game played between two players. In the project, the user plays against a computer.
The computer randomly selects Rock, Paper, or Scissors. The program compares the player's choice with me the computer's choice and displays the result.

### 2. Problem Statement
The objective is to develop a Python-based Rock-Paper-Scissors game that allows a user to play multiple rounds against the computer and keeps track of the scores.

### 3. Objectives
1. To create an interactive console-based game.
2. To implement decision-making using conditional statements.
3. To use loops for repeated gameplay.
4. To generate a random computer choice.
5. To maintain player and computer scores.
6. To handle invalid user input.

### 4. Requirements

#### Hardware Requirements

### 5. Algorithm
1. Start the program.
2. Create a list containing Rock, Paper, and Scissors.
3. Display the game menu.
4. Accept the user's choice.
5. Validate the user's choice.
6. Generate the computer's choice using random selection.
7. Compare the two choices.
8. Display the winner.
9. Update the score.
10. Continue the game until the user selects Exit.
11. Display the final score.
12. Stop the program.

### 6. Game Rules
Rock beats Scissors.
Scissors beats Paper.
Paper beats Rock.
Same choices result in a Draw.

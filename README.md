# Rock-Paper-Scissors1-python

## Project Overview

A simple Rock  Paper Scissors game developed using python.
In this game, the player competes against the computer. The player selects Rock, Paper, or Scissors, and the computer randomly one option.
The program compares both the choices and determines the winner.

## Objectives
- To develop a simple interactive Pythongame.
- To understand conditional statements.
- To use loops for repeated gameplay.
- To understand random selection.
- To practice user input and output.
- To maintain and display scores.

## Rules
- Rock beats Scissors
- Scissors Beat Paper
- Paper beats Rock
- If both choices are the same, the result is a draw.

## How to Run
1. Install Python 3.6 .
2. Open the project in VSCode.
3. Open 'main.py' .
4. Run the program.
5. Select Rock, Paper, or Scissors.
6. The computer will randomly select its choice.
7. The result and score will be displayed.
